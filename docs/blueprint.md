# **App Name**: Meal Mate

## Core Features:

- User Authentication: Secure sign-in options via Google and Apple accounts to personalize the user experience.
- Personalized Onboarding: Guided setup after sign-in to define user-specific diet goals and a monthly grocery budget.
- Home Dashboard: A central tab providing a personalized overview of upcoming meal plans, quick stats, and notifications.
- Meal Planner: Tool to create, view, and manage daily and weekly meal schedules, allowing users to add or rearrange recipes.
- Recipe Browser: Explore a curated collection of recipes, view detailed instructions, ingredients, and add them to meal plans.
- Shopping List Management: A globally accessible tool to add, remove, and organize grocery items, with optional smart suggestions from meal plans.
- AI Meal Plan Suggestions: Utilize a generative AI tool to suggest personalized meal plans based on the user's defined diet goals, grocery budget, and available recipe options.

## Style Guidelines:

- The visual scheme will be light to evoke clarity and freshness. The primary color is a calm yet distinct blue (#266FD9), representing trustworthiness and systematic planning.
- The background color is a very light, almost off-white with a subtle cool tint (#F5F6F8), ensuring high legibility and an airy feel.
- The accent color is a refreshing blue-green (#0F93B6), offering a vibrant contrast to highlight calls to action and important information.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly legible qualities across various text lengths and screen sizes, ideal for informational and planning content.
- Utilize clean, line-based vector icons for all navigation elements and actions, ensuring clarity, consistency, and easy recognition across the application.
- Prioritize a clear information hierarchy and intuitive mobile-first design. Implement accessible forms for input, ample white space for readability, and the explicit five-tab bottom navigation structure for core features.
- Implement subtle, smooth transitions for navigation between tabs, loading states, and when items are added to lists, providing a polished and responsive user experience without being distracting.
